
# Basic HTML Website

This project is a simple **multi‑section HTML website** built as part of the [roadmap.sh](https://roadmap.sh/projects/basic-html-website) learning path.  
It demonstrates semantic HTML structure, navigation, and layout without relying on external frameworks.

---

## 📂 Project Structure
- `index.html` → Main file containing all sections:
  - **Header**: Name and navigation links
  - **Intro Section**: Title and subtitle
  - **Projects Section**: List of sample projects
  - **Work Experience Section**: Roadmap.sh profile and open‑source contributions
  - **Education Section**: Academic background and courses
  - **Reviews Section**: Teacher testimonials
  - **Footer**: Copyright

---

## 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Navigate through sections using the top navigation bar.

---

## 🛠 Features
- Pure **HTML layout** (no external CSS/JS required).
- Semantic tags: `<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`.
- Multi‑column layout for Projects, Work Experience, and Education.
- Contact/Reviews section for testimonials.

---

## 📖 Learning Goals
- Practice writing clean, semantic HTML.
- Understand basic website structure.
- Learn how to organize content into sections.
- Prepare for adding CSS and JavaScript in future projects.
