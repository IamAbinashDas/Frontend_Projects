
# 📅 Datepicker UI

A simple, responsive, and customizable **Datepicker UI** built with **HTML, CSS, and JavaScript**.  
This project is part of my **Frontend Projects** collection, designed to help practice and showcase core web development skills.

---

## 🚀 Features
- Clean and minimal calendar popup
- Select dates with a single click
- Navigation for previous/next months
- Highlights current day
- Responsive design for different screen sizes
- Easy to integrate into any project

---

## 📂 Project Structure
```
Datepicker_UI/
│── index.html      # Main HTML file
│── style.css       # Styling for the datepicker
│── app.js          # JavaScript logic
│── README.md       # Documentation
```

---

## 🛠️ Installation & Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/IamAbinashDas/Frontend_Projects.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Frontend_Projects/Datepicker_UI
   ```
3. Open `index.html` in your browser to see the datepicker in action.

---

## ⚙️ How It Works
- Click on the input field to open the calendar.
- Use the arrows to navigate between months.
- Select a date, and it will be displayed in the input field.

---

## 🎨 Customization
You can easily tweak the **CSS** to:

- Adjust spacing and layout
